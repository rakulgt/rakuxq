## 变化

- 匿名交互记录新增“复制 FEN”和“打开局面”按钮，后者按 `xiangqiai.com/#/<piece_placement>%20<w|b>` 生成链接。
- 新增 `/developers` 公开技术教程，提供 curl、Python、JavaScript 示例和响应处理约定。
- 新增 `POST /api/public/trial-keys`：随机临时 Key 有效 6 分钟、明文只显示一次、同来源单活，并配置匿名 HMAC 来源指纹、全局活跃上限与 Nginx 入口限流。
- 首次生成服务器专用 `trial-key-pepper`，不写入 Git、普通日志或部署记录。

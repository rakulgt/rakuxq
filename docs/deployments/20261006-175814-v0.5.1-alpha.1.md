## Delivered behavior

- Anonymous event detail now uses two simultaneous bounds: at most 720 hours and at most 100,000
  rows. The hourly retention timer enforces both bounds even when the API receives no traffic.
- `GET /api/public/events` provides opaque cursor pagination in pages of up to 100 rows. The homepage
  starts with 50 rows and can continuously request older pages until the retained set is exhausted.
- Existing SQLite data was migrated in place. At verification time it retained 2,092 recent event
  rows and preserved the lifetime counter of 2,297 successful interactions.
- A local DB-IP City Lite MMDB resolves approximate country, region, city, and city-center coordinates.
  The 126,998,165-byte database is stored outside release directories and is reused across releases.
- Raw client IP addresses are used only in request memory for local lookup. They are not written to
  the public metrics database or returned by public APIs. Existing images and full interaction audits
  remain governed by the independent 12-hour deletion policy.
- The homepage displays a 30-day trend, location column, retention explanation, pagination controls,
  and the required DB-IP attribution. Existing rows predate geolocation and therefore have no location;
  new authenticated recognition calls populate it when a public IP can be resolved.

gate had not passed and restored the previous release. Commit `b059f48` changed the gate to use the
release interpreter explicitly; the second versioned deployment then passed. No metrics, uploads,

## 部署内容

- 有效 API Key 的识别调用保存原始上传文件、表单参数、完整响应、HTTP 状态、耗时、请求 ID、识别结果和 Key ID。
- 明文 API Key、`Authorization` 和 `X-API-Key` 不写入审计记录。
- 无效、缺失、过期或吊销 Key 的请求不保存请求体，避免形成匿名文件存储入口。

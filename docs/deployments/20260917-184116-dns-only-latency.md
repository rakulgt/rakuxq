## 边界与回滚

仅 DNS 模式不再获得 Cloudflare 代理层的 WAF、源站隐藏和抗 DDoS 能力，但 API Key、Nginx 限流、
并发限制、上传大小限制及源站 TLS 保持有效。如需回滚，可在 Cloudflare 把精确记录重新设为代理，
随后必须复测中国大陆客户端的上传速度和完整 HTTPS 链路。

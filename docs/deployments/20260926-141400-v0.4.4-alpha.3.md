## 变更原因

- 最近一次客户端请求总耗时 43.539 秒，其中服务器等待完整请求体 43.224 秒，应用识别仅 315 毫秒；性能退化发生在上传链路，不在视觉算法。
- `vpn.xq.rakubank.com` 是多层子域名，Cloudflare 免费 Universal SSL 默认无法为橙云入口提供边缘证书，实际测试发生 TLS 握手失败。
- 新增一级子域名 `xq-fast.rakubank.com`，使用 Cloudflare 免费橙云；原 `xq.rakubank.com` 继续灰云直连，两个入口共享应用、鉴权、限流、短期审计和匿名计时。

## 变化

- 新增 `/lab` 原生棋局实验室与 `/fen/<标准 FEN>` 固定直达入口，兼容两字段、六字段、`/#/<FEN>` 和 `/lab?fen=<FEN>`。
- 增加棋盘翻转、合法走子、悔棋、重做、时间轴、非破坏变化树和浏览器本地恢复。
- 增加 FEN、ICCS、RakuXQ JSON 导入，以及 FEN、研究链接、ICCS、JSON 和 PNG 导出。
- 为红黑双方提供独立的评分、提示和自动代走控制；分析证据包含固定红方视角评分、最佳着法、PV、深度、节点、耗时、引擎和网络摘要。
- 官方生产站继续不部署许可受限的 Pikafish NNUE 权重；引擎未开放时分析按钮与相关设置直接禁用，棋盘研究能力保持完整。

## Behavior

The public feed displays 时间 / 状态 / 来源国家 / 简化 FEN / 推荐招法, followed by existing
confidence, visual timing and actions. The new column contains only Chinese move notation from
`analysis.best_move.notation`, never the score, advantage label or KO text. Missing answers and
terminal/error results display a dash. The layout adds a desktop column and a compact mobile label.
Homepage CSS/JS cache versions are `0.5.3a2`.

The metrics migration adds only nullable `recommended_move TEXT` to existing public events.
Completed fused solves attach their already-computed move to the exact request event and matching
FEN; this neither adds interactions nor invokes another search. Startup imports matching completed
responses still held in 12-hour audits, without exporting images or extending image retention.

Before/after comparison: 3,706 retained events; lifetime 3,911 successful FEN records, 3,838 accepted,
73 requiring review. All counters stayed unchanged; 60 existing events received a recommendation.
Recommendation retention and pagination follow the original event's 30-day/100,000-row policy.

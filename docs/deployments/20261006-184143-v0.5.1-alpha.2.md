## Reason and delivered behavior

- A real authenticated request was resolved by the city database as `Jinrongjie (Xicheng District)`.
  This describes an ISP or VPN egress mapping, not a sufficiently reliable statement about the user's
  physical city. Public location output is therefore deliberately reduced to approximate country only.
- New events persist only country code and localized country name. Public event and aggregate APIs no
  longer expose region, city, latitude, or longitude. Database initialization clears those fields from
  retained legacy rows; the existing columns remain only for a backward-compatible in-place migration.
- The homepage now labels the metric as `平均视觉识别耗时` and the event column as `视觉识别`.
  `duration_ms` begins after the uploaded image body has reached the application and covers image decode,
  board pose/layout inference, 90-point classification, and visual post-processing. It excludes client
  upload time, authentication, response delivery, and Pikafish/NNUE search.
- Engine timing remains separately available in solution responses through the analysis/search timing
  fields; it is not mixed into the public recognition-duration metric.

## Privacy boundary

Raw IP addresses are still used only in request memory for local country lookup and are neither stored in
the public metrics database nor returned by public APIs. Country remains approximate because a VPN or ISP
egress can terminate in another country. Original image retention remains independently limited to 12 hours.

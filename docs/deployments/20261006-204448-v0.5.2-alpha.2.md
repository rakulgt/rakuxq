## Delivered behavior

- RakuXQ Lab is free for public, non-commercial study and no longer displays, requests, stores, or
  sends an API Key. Board play, analysis, per-side assistance, and two-side automatic play use the
  dedicated browser channel.
- Added `POST /api/lab/analyses` as a same-origin, non-OpenAPI endpoint. It accepts at most 3000 ms
  per search and emits `Cache-Control: no-store`; foreign or missing origins are rejected.
- Nginx applies a separate per-IP budget of 60 requests per minute, burst 8, and one concurrent Lab
  engine request. The endpoint is isolated from the authenticated `/v1/*` routing budget.
- `/v1/solutions`, `/v1/analyses`, and `/v1/solve` retain API Key validation and the configured
  engine-key allowlist. Future charging remains limited to programmatic remote hosting, not on-site
  Lab study.

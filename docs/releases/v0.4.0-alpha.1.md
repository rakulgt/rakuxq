# RakuXQ v0.4.0-alpha.1 — Lab

发布日期：2026-09-19

## 核心变化

- 新增 `https://xq.rakubank.com/lab` 原生棋局实验室。
- 标准两字段或六字段 FEN 可以直接拼接到 `https://xq.rakubank.com/fen/`；同时兼容
  `/#/<FEN>` 与 `/lab?fen=<FEN>`。
- 棋盘支持合法着法、吃子、翻转、悔棋、重做、回合定位与非破坏变化树。
- 红黑双方可独立选择关闭、只评分、最佳着法提示或自动代走。
- 引擎结果保留固定红方视角评分、ICCS、PV、深度、节点、耗时、引擎版本和网络 SHA-256。
- 支持 FEN、ICCS、RakuXQ JSON 导入，以及 FEN、研究链接、ICCS、JSON、PNG 导出。
- 棋谱默认只保存在浏览器本地；页面中的 API Key 只保留在当前内存会话。

## 兼容与授权边界

原有 `/v1/recognitions`、`/v1/fen`、`/v1/analyses` 和 `/v1/solve` 契约保持兼容。官方生产站
继续只部署视觉模型；在取得托管授权或切换到权利清晰的自有权重前，不部署 Pikafish 官方
NNUE 权重。实验室在没有引擎时仍完整提供走棋、打谱、变化树与导入导出。

## 验证

- Python API/领域测试：62 项通过。
- Web 领域测试：8 项通过，覆盖固定 FEN 前缀、六字段规范化、三种地址入口和变化树。
- 浏览器桌面实测：用户提供的长 FEN 地址直接加载，棋子布局、行棋方与外部跳转正确。
- 浏览器交互实测：本地 Pikafish 分析、走棋、悔棋、双分支保留及 FEN 导入通过。
- 390×844 移动视口实测：棋盘完整显示，控制区按单列工作面折叠，无横向滚动。

# RakuXQ v0.1.1-alpha.1

## 中文

这是 RakuXQ 官方托管 API 的首个可运营版本。

- 为每位客户签发独立 API Key，支持到期、续期与吊销。
- 服务端只保存高熵 Key 的 SHA-256 哈希，明文只在签发时显示一次。
- 过期响应包含微信 `lgtqcn` 和 `39 元人民币/年` 的结构化续费信息。
- 正式 JSON 入口为 `https://xq.rakubank.com/v1/recognitions`。调用方只在
  `status=accepted` 时消费 `fen`。
- 增加 systemd、Nginx、HTTPS、限流、资源上限和可回滚的版本化部署。

MIT 开源源码仍然免费。`39 元/年` 只对应维护者提供的官方服务器推理、带宽、
密钥和运维服务。第三方 ONNX 权重仍不随 GitHub 源码包重新分发。

## English

This is the first operable release of the hosted RakuXQ API.

- Issue independent customer API keys with expiration, renewal, and revocation.
- Store only SHA-256 hashes of high-entropy keys; plaintext appears once at issuance.
- Return structured renewal details when a key expires.
- Publish the hosted JSON endpoint at `https://xq.rakubank.com/v1/recognitions`; clients consume
  `fen` only when `status=accepted`.
- Add systemd, Nginx, HTTPS, rate limits, resource controls, versioned deployment, and rollback.

The MIT-licensed source remains free. The CNY 39/year fee applies only to the maintainer-hosted
inference, bandwidth, key management, and operational service. Third-party ONNX weights remain
excluded from GitHub source archives.

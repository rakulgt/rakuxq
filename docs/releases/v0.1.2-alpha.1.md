# RakuXQ v0.1.2-alpha.1

发布日期：2026-09-17

本版本为官方托管 API 增加短期、可审计且自动过期的质量反馈闭环。

## 主要变化

- 有效 API Key 的每次识别调用保存原始上传文件、表单参数、完整响应、HTTP 状态、耗时和 Key ID。
- 记录最长保留 12 小时，每分钟执行过期清理。
- 设置 2 GiB 总容量保护；容量不足时优先删除最旧记录。
- 无效、缺失、过期或吊销 Key 的请求不保存请求体，明文 Key 永不进入日志。
- Nginx 访问和错误日志改为小时级轮转，旧轮转文件同样受 12 小时清理约束。
- 自托管默认仍不启用图片留存；只有显式配置审计目录才启用。

## 数据边界

短期审计用于发现识别失败、统计准确率和稳定性，不构成永久数据集或训练授权。记录不进入 Git，
也不会自动转入训练流程。

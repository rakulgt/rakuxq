# RakuXQ v0.5.0-alpha.4 — Evidence-Based Recognition Gate

发布日期：2026-09-28

## 本次改进

- 完整棋盘常规定位与自动放行门槛从 `0.50` 调整为 `0.45`，减少关键点模型系统性低估造成的误拒。
- 新增多证据联合放行：完整棋盘定位置信度在 `0.30–0.45` 时，只有全部明确棋子最低置信度达到 `0.90`、全部空位最低置信度达到 `0.80`，且帅将、行棋方和局面合法性均通过，才允许进入引擎。
- 部分棋盘、画外区域和未知遮挡格继续按用户确认的规则默认空，对应门槛保持 `0.30`；明确棋子的常规底线仍为 `0.75`。
- 每次响应通过 `prediction.metadata.acceptance_gate` 披露所用门控档位、实测值和实际阈值；强内容证据放宽会增加 `STRONG_CELL_EVIDENCE_RELAXED_BOARD_CONFIDENCE`。

## 真实误拒回归

一张约 184 KB 的正常棋局视频帧在上一版本中用时约 412 毫秒完成视觉推理，但棋盘定位置信度 `0.490676` 略低于 `0.50`，尽管棋子最低置信度为 `0.908490`、空位最低置信度为 `0.805594`、帅将和行棋方完整且无阻断性违法，仍被机械判为 `review_required`。

生产更新后在服务器内部直接重跑同一张 12 小时短期审计原图，不导出图片：

- 状态变为 `accepted`；
- 门控档位为 `standard`，生效棋盘门槛 `0.45`；
- 输出 FEN `2b1kab2/4a4/1R7/1N7/p1r5P/1N4P2/P8/4B4/4A4/4KAB2 w`；
- Pikafish NNUE 返回 `车八进二 +838`。

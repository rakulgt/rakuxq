# RakuXQ v0.5.0-alpha.6 — Auditable Highlight-Resistant Recognition

发布日期：2026-10-04

## 本次改进

- 修复棋盘应用的选中光圈、落子高亮等动态 UI 效果导致正常局面被反复标记为 `review_required` 的问题。
- 低置信明确棋子不再由单一固定阈值裁决，而是联合使用同图棋种原型、帅/将颜色锚点、模型第一与第二候选间隔和局面合法性。
- 只有低置信候选可进入融合；高置信棋子和帅/将身份不可被覆盖。阵营纠正必须保持棋种不变，并严格减少阻断性局面违法。
- 对仅有一个边界弱格的正常局面，模型具有决定性类别间隔时可提升有效置信度；未知格、多弱格和非法局面不适用。
- 响应通过 `LOW_CONFIDENCE_PIECE_CONFIRMED`、`LOW_CONFIDENCE_EMPTY_CONFIRMED` 或 `CAMP_COLOR_LEGALITY_REFINEMENT` 披露所用路径，并在 `prediction.metadata.low_confidence_visual_fusions` 保存完整依据。

## 回放验证

- 使用正式服务 12 小时短期审计池中的 8 张历史复核图片进行本地程序回放。
- 6 张内容完整、实际可识别但曾被固定阈值误拦的图片全部变为 `accepted`。
- 2 张严重缺失棋盘、含大量未知格且产生阻断性局面违法的图片继续保持 `review_required`。
- 回放原图只用于本次短期诊断和验证，不进入仓库、发布物或长期训练集。

## 安全边界

本版本没有降低全局 `0.75` 单格门槛，也没有恢复曾导致红黑阵营误传播的全盘颜色改写。证据不足时系统仍要求复核。

# RakuXQ v0.5.0-alpha.5 — Explicit Red/Black Score Labels

发布日期：2026-09-28

## 本次改进

- 普通局面的人类可读评分由 `+N/-N/0` 改为 `红优 N/黑优 N/均势 0`。
- 强制杀棋由 `KO(+N)/KO(-N)` 改为 `红方 KO(N)/黑方 KO(N)`。
- `score.value` 仍保留红方固定视角的有符号整数：正数红优、负数黑优、零为近似均势；现有程序可以继续比较数值，不受显示文字变化影响。
- Apple 快捷指令直接使用的 `display_text` 和 RakuXQ Lab 引擎面板同步采用显式阵营标签。

## 生产验收

- 经典杀棋局面返回 `前炮进二 红方 KO(2)`，结构化 `value=2`。
- 普通优势局面返回 `车八进二 红优 826`，结构化 `value=826`。
- 黑方优势与均势的单元回归分别验证 `黑优 243` 和 `均势 0`。

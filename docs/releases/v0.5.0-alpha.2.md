# RakuXQ v0.5.0-alpha.2 — Personal NNUE Runtime

发布日期：2026-09-28

## 本次改进

- 在正式服务器安装经 SHA-256 校验的 Pikafish 2026-09-06 Linux 程序与配套 NNUE，文件继续位于 Git 仓库之外。
- 三个引擎路由增加独立 Key ID 白名单；当前仅维护者 `owner-lgtqcn` 的个人 Key 可进行非商业验证。
- 六分钟临时 Key、普通识别 Key 和客户 Key 均在启动引擎前返回 `403 ENGINE_ACCESS_DENIED`，识图接口保持原有权限与行为。
- 部署脚本安全保留引擎路径、权重路径、版本和非秘密白名单，普通发布不再清空运行配置。
- 生产采用单常驻进程、单线程、64 MiB 哈希和串行搜索，受 systemd 1.2 GB 内存上限保护。

## 验证

- Python：91 项测试通过；Ruff 和 Mypy 20 个源文件通过。
- Web：9 项测试通过；部署脚本通过服务器 Bash 语法检查。
- Wheel：`rakuxq_api-0.5.0a2-py3-none-any.whl`，SHA-256 为 `b2be477916a10b23c64e271e438337224f158cbffa48e463b9cbfb619cddcfc8`。
- 两个公网入口均返回 `0.5.0a2`、`engine_configured=true`、`engine_ready=true`。
- 真实服务器残局计算返回 `前炮进二 KO(+2)`，耗时 101 毫秒；临时 Key 调用解题接口返回 `403 ENGINE_ACCESS_DENIED`。
- 服务保持 `active`、`NRestarts=0`；引擎加载后的峰值内存约 517 MiB，低于 1.2 GB 上限。

## 授权边界

本次安装只用于维护者个人、非商业技术验证。Pikafish 程序和官方 NNUE 权重不进入 MIT 仓库，
也不向临时 Key、普通客户 Key 或付费托管用户开放。任何商业或公共引擎服务仍须先取得相应许可，
或切换为权利清晰的 RakuXQ 自有权重。

# RakuXQ v0.3.0-alpha.1

Release date: 2026-09-18

## 中文

这是 RakuXQ 第二阶段的第一个源码预发布：在现有图片转 FEN 能力之外，增加可替换的 UCI
引擎边界、Pikafish 本地适配器以及两个新接口。

- `POST /v1/analyses`：已经确认的 FEN → 最佳着法、评分、PV 和搜索元数据。
- `POST /v1/solve`：图片 → 视觉门控 → FEN → 最佳着法；视觉未自动通过时不启动引擎。
- 评分永远以红方为视角，使用整数 `+N/-N/0`，杀棋使用 `KO(+N)/KO(-N)`。
- Pikafish 使用单个常驻进程，默认 1 线程、64 MiB Hash，搜索预算受服务端上限约束。
- 引擎程序和 NNUE 权重由用户另行安装，不包含在 MIT 仓库、wheel、容器或生产服务中。

真实技术验证使用官方 `Pikafish-2026-09-06`：经典残局返回 `e6e8` 与 `KO(+2)`；一张真实
棋盘图片通过 `/v1/solve` 返回正确 FEN、`f2f9` 与 `KO(+5)`，端到端约 1.11 秒。全部 61 项
测试、Ruff、mypy、wheel 构建及真实 Uvicorn 冒烟通过。

官方 Pikafish NNUE 权重禁止未经许可的商业使用。本版本只完成本地非商业技术验证，未部署到
`xq.rakubank.com`。未来收费托管必须先取得授权或使用权利清晰的 RakuXQ 自有权重。

## English

This is the first source prerelease of RakuXQ phase two. It adds a replaceable UCI engine boundary,
a local Pikafish adapter, `POST /v1/analyses`, and the combined `POST /v1/solve` flow. Scores are
integer values on a fixed red perspective, with `KO(+N)` and `KO(-N)` for forced mates.

The executable and NNUE network are installed separately and are not part of the MIT repository,
wheel, container, or production service. Real interoperability testing used the official
`Pikafish-2026-09-06` release. All 61 tests, Ruff, mypy, wheel construction, and live Uvicorn smoke
tests passed.

The official Pikafish network prohibits commercial use without permission. This prerelease is a
local, non-commercial technical validation and is not deployed to `xq.rakubank.com`.

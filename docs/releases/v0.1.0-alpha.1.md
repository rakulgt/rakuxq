# RakuXQ v0.1.0-alpha.1

首个公开预发布版本。RakuXQ 现在可以通过本地 HTTP API，把中国象棋截图和实体棋盘照片转换为可审计的 FEN 候选。

## 主要能力

- 本地 ONNX + OpenCV 推理，不调用图生文大模型。
- 棋盘定位、透视校正和 90 个交叉点分类。
- `/v1/recognitions` 完整 JSON 与 `/v1/fen` 纯文本接口。
- 适配 Apple 快捷指令上传图片并取得 FEN。
- 局面合法性检查、置信度门控和 `review_required` 拒识。
- 局部棋盘可见性规则与同图视觉原型复核。
- 默认不持久化图片，也不将用户图片自动纳入训练。

## Important notes

This is the first public pre-release of RakuXQ. It provides a local, auditable Xiangqi image-to-FEN HTTP API using ONNX Runtime and OpenCV.

- Third-party ONNX weights are **not included** in the source release. Follow `models/README.md` and verify them with `scripts/verify_models.py`.
- The current real-world sample set is promising but still too small for a general near-100% accuracy claim.
- Static board photos usually do not reveal the side to move; clients must supply `red` or `black` for a complete FEN.
- Public hosting, authentication, rate limiting, and the NNUE solving phase are not part of this release.

See the bilingual README for setup, API examples, limitations, privacy, and the roadmap.

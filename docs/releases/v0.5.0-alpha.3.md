# RakuXQ v0.5.0-alpha.3 — Tolerant Image-to-Solution

发布日期：2026-09-28

## 本次改进

- 完整棋盘的定位与联合自动放行门槛由 `0.55` 调整为 `0.50`，覆盖视频帧中棋盘四角略模糊、但棋子分类稳定的情况。
- 部分棋盘、画外补空和画面内未知遮挡格补空的门槛由 `0.35` 调整为 `0.30`。
- 明确棋子的最低置信度继续保持 `0.75`；放宽棋盘定位不会把低可信棋种静默送入引擎。
- `/v1/solve` 始终返回顶层 `display_text`：成功时给出“着法 + 评分”，需要复核时给出明确重拍提示。

## 真实故障回归

用户连续上传的两张约 188 KB 视频帧在上一版本中因棋盘定位置信度分别为 `0.5339` 和 `0.5330` 而返回 `review_required`，尽管所有棋子最低置信度超过 `0.91`、空位最低置信度超过 `0.80` 且局面无阻断性异常。

新版本在生产服务器内部直接重跑两张短期审计原图，不导出图片：

- 两张均变为 `accepted`；
- 两张均生成 FEN `2b1kab2/4a4/2n1r4/p6RC/4P4/2B1n1P2/P3N3P/2N6/9/3AKAB2 w`；
- 自动判断均为红方走；
- NNUE 分别返回 `车二退一 +629` 与 `车二退一 +628`。

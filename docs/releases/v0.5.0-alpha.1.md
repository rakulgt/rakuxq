# RakuXQ v0.5.0-alpha.1 — FEN to Solution

发布日期：2026-09-28

## 本次改进

- 新增 `POST /v1/solutions`：把两字段或六字段中国象棋 FEN 转换为最佳着法、局面评分和主要变化。
- `time_ms` 可选，默认 3000 毫秒、允许 50–10000 毫秒；响应区分请求预算、生效预算和实际耗时。
- 新增规范中文着法：红方使用中文数字，黑方使用阿拉伯数字，并处理前、中、后同路棋子。
- 评分固定采用红方视角：正数红优、负数黑优；强制杀棋使用 `KO(+N)` 与 `KO(-N)`。
- 新增 `display_text`，可被 Apple 快捷指令或终端直接显示，例如 `前炮进二 KO(+2)`。
- Lab 默认三秒搜索，优先展示中文最佳着法和中文主要变化；ICCS 原值继续保留供程序执行。

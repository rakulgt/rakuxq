# Apple 快捷指令调用 RakuXQ

目标是从系统分享菜单或相册选取一张象棋截图，上传到 RakuXQ，解析完整 JSON，并仅在结果被自动接受时把 FEN 复制到剪贴板或传给后续动作。

## 快捷指令动作

1. 添加“接收共享内容”，类型选择“图像”。
2. 如果没有共享输入，添加“选择照片”。
3. 添加“转换图像”，格式选择 JPEG；这能统一截图、相册照片和不同 iOS 版本的上传格式。
4. 添加“从菜单中选取”，提供“红方走”和“黑方走”两个选项。
5. 分别把文本变量设为 `red` 或 `black`。
6. 添加“获取 URL 内容”：
   - URL：`https://xq.rakubank.com/v1/recognitions`
   - 方法：`POST`
   - 请求头：`Authorization` = `Bearer <你的 API Key>`
   - 请求正文：`表单`
   - `image`：类型选“文件”，值为输入图片
   - `side_to_move`：类型选“文本”，值为上一步变量
7. 从返回的字典取得 `status`，添加“如果”判断：
   - 当 `status` 等于 `accepted`：取得 `fen`，复制到剪贴板或传给 NNUE 解题步骤。
   - 其他情况：不提取 FEN，显示 `warnings` 并提示重拍。
8. 当响应代码为 `API_KEY_EXPIRED` 时，显示“请联系微信 lgtqcn 续费，39 元人民币/年”。

## 为什么需要选择行棋方

实体棋盘静态图片通常不包含“轮到谁走”的信息。棋子布局可以从图片识别，但完整引擎 FEN 还需要行棋方。未来可针对具有明确回合标记的特定 App 截图增加自动判断；通用接口不能凭空猜测。

## 错误处理

当接口返回非 2xx 状态时，快捷指令应显示响应中的 `detail`。常见情况包括 API Key 缺失、无效或过期，模型未就绪、棋盘未找到、图片过大或格式不支持。`review_required` 是成功的 JSON 响应但不应自动消费 FEN。

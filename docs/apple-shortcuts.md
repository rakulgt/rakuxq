# Apple 快捷指令调用 RakuXQ

目标是从系统分享菜单或相册选取一张象棋截图，上传到 RakuXQ，解析完整 JSON，并仅在结果被自动接受时把 FEN 复制到剪贴板或传给后续动作。

## 快捷指令动作

1. 添加“接收共享内容”，类型选择“图像”。
2. 如果没有共享输入，添加“选择照片”。
3. 添加“转换图像”，格式选择 JPEG；这能统一截图、相册照片和不同 iOS 版本的上传格式。
4. 添加“从菜单中选取”，提供“自动判断（下方是我方）”、“红方走”和“黑方走”三个选项。
5. “自动判断”的文本变量设为 `auto`；其他两项分别设为 `red` 或 `black`。如果还要把同一个值直接拼到
   `https://xiangqiai.com/#/<棋子布局>` 后面，菜单值可以直接使用 `%20w` 或 `%20b`；API 会兼容
   并规范化，不需要额外判断。
   如果菜单分支意外没有产生文本，服务端也会把空值当作 `auto`；不过 `image` 字段仍必须明确连接转换后的棋盘图片。
6. 添加“获取 URL 内容”：
   - URL：`https://xq.rakubank.com/v1/recognitions`
   - 方法：`POST`
   - 请求头：`Authorization` = `Bearer <你的 API Key>`
   - 请求正文：`表单`
   - `image`：类型选“文件”，值必须为第 3 步转换后的棋盘图片，不能选择“菜单结果”
   - `side_to_move`：类型选“文本”，值为上一步变量
7. 从返回的字典取得 `status`，添加“如果”判断：
   - 当 `status` 等于 `accepted`：取得 `fen`，复制到剪贴板或传给 NNUE 解题步骤。
   - 其他情况：不提取 FEN，显示 `warnings` 并提示重拍。
8. 当响应代码为 `API_KEY_EXPIRED` 时，显示“请联系微信 lgtqcn 续费，39 元人民币/年”。

例如菜单值为 `%20w` 时，可以直接使用：

```text
https://xiangqiai.com/#/<piece_placement>%20w
```

不要把 `%20w` 再做一次 URL 编码，否则会变成 `%2520w`。

返回 JSON 中的 `fen` 已经严格等于 `piece_placement + 真实空格 + w/b`，不包含
`- - 0 1`，也不包含网站 URL。需要完整六字段形式的程序使用 `full_fen`。

官方托管服务会把有效 Key 调用的原图和交互结果短期保存最多 12 小时，用于早期准确率与稳定性
分析；之后自动删除，不会自动进入永久数据集或训练集。明文 API Key 不进入审计记录。

## 自动判断的语义

实体棋盘静态图片本身通常不包含“轮到谁走”的客观信息。除明确的红方或黑方值外，接口都采用这条业务规则：下方一侧是正在请教的我方，因此就认为轮到该方走。程序直接比较原始上传图片中帅、将的像素中心高度：帅在下返回 `w`，将在下返回 `b`；棋盘之后如何旋转或标准化都不会改变该结论。无法唯一判断时不猜测，快捷指令应提示用户重拍或手动选择行棋方。

## 错误处理

当接口返回非 2xx 状态时，快捷指令应显示响应中的 `detail`。常见情况包括 API Key 缺失、无效或过期，模型未就绪、棋盘未找到、图片过大或格式不支持。`review_required` 是成功的 JSON 响应但不应自动消费 FEN。

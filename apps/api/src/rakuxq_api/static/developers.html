三种调用方式

领取临时 Key 后，下列示例会自动替换占位符。

curl
curl -X POST https://xq.rakubank.com/v1/recognitions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "image=@board.jpg" \
  -F "side_to_move=red" \
  -F "orientation=auto"
Python
import requests

response = requests.post(
    "https://xq.rakubank.com/v1/recognitions",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    files={"image": open("board.jpg", "rb")},
    data={"side_to_move": "red", "orientation": "auto"},
    timeout=60,
)
result = response.json()
fen = result["fen"] if result.get("status") == "accepted" else None
print(fen)
JavaScript

RULES

接入约定

  • 只在 status=accepted 时自动使用 fen。
  • review_required 表示应让用户检查或重新拍照。
  • 未拍到、被手遮挡或无法确认的格点按空位处理，并通过警告字段说明。

第一条　处理目的与必要范围

1. 为完成用户主动请求，我们接收棋盘图片、局面字符串、行棋方及计算设置，进行局面识别或分析；为凭据验证、期限管理、限流和安全，处理相应密钥验证信息及必要请求信息。不同目的应分别确定合法处理基础，不把履行识图订单直接等同于获得训练同意。
2. 已鉴权调用的短期故障审计可能包含原图、表单字段、完整响应、请求时间、请求标识、密钥内部标识、文件信息、客户端软件标识及必要技术元数据。密钥明文不写入审计；这些内部记录不对公众展示，也不整体进入训练库。
3. 源站或加速网络在建立连接、转发及安全处理时会接触必要的IP、请求头等网络信息。当前应用公开地理统计只在请求内存中通过本地库解析近似国家，不将原始IP写入公开统计库，不保存地区、城市或坐标；这不等于声称运营链条中从未处理任何网络信息。
4. 领取临时密钥的防滥用指纹、密钥哈希和期限用于签发与防滥用；与有效凭据或其他信息有关联时，应按相应可识别性保护，不能仅因使用哈希就宣称全部匿名。
5. 浏览器本地保存的打谱和设置由相应设备保存。只有您调用服务器分析或明确提交时，相关局面才发送至服务器；仅在本地走棋或导入文件，不当然把整份棋谱上传到平台。

第二条　训练用途及无关信息排除

1. 在适用的棋局许可及个人信息处理条件满足后，平台可以筛选必要的FEN、着法、胜负和经核查的棋盘、棋子图像样本，用于象棋识别、评估、着法研究和模型评测，不用于识别人脸、建立身份画像、个性化广告或无关模型用途。
2. 优先保留不关联自然人的结构化棋局；将时间、账号、设备、原始IP、文件元数据及请求关联标识与训练内容分离或删除。去标识化但仍可重新关联个人的数据，继续按个人信息保护，不将其等同于不可复原的匿名信息。
3. 对视觉训练，仅提取必要棋盘或棋子区域，并执行与风险相适应的检查。人脸、聊天、账号、位置、水印中的个人信息及其他无关内容应排除；不能可靠排除的样本不纳入。平台不以“不主动查看”为由宣称无关信息不需要保护。
4. 如确有必要以仍包含个人信息的数据训练，应先明确个人信息种类、必要性、处理方式、期限、影响及行使权利的渠道，并依法取得所需同意或其他合法基础。非必要个人信息训练不得与基本服务捆绑，敏感个人信息、未成年人信息、向其他处理者提供或出境等依法需要的程序应另行履行；本说明不概括授权上述行为。
5. 上传者的版权或棋局许可，不替代第三人的个人信息权利，也不替代第三方模型、教师评分、训练数据及工具的许可。

第三条　保存期限与删除

1. 原图及完整交互审计：最长12小时，因容量保护可能更早删除。未经另行明确合法依据，不保留整张原始截图作为长期训练素材。
2. 训练样本：最长3年，自首次进入训练库之日起计算；适用于结构化棋局及符合筛选条件的棋盘、棋子裁切样本。复制、转存、重新标注和备份不重置期限。恢复备份时应执行到期清理和已生效删除清单，不恢复被禁止继续使用的样本。
3. 公开交互明细：在线可见记录最多30天且最多10万条；任一上限触发淘汰最旧明细。累计层只长期保留不含个人关联信息的汇总数字。
4. 公开统计的隔离备份按最长30天滚动淘汰，不用于训练或日常公开查询；这意味着在线过期明细可能在隔离备份中随快照暂存，不承诺其在在线过期同一时刻从所有备份物理消失。恢复后应先执行过期及删除规则，再对外开放。
5. 授权接受记录自该次明确确认之日起最长保存3年，仅保存适用版本、正文校验值、时间和最小必要凭据，不包含原图、完整棋谱、原始IP或密钥明文；不因普通浏览而重新起算。到期后如需新的确认，应再次明确提示。训练样本必要的来源与合法性记录随样本管理，并适用样本最长3年及最小必要原则，不另行增加无关身份资料。
6. 订单、支付、投诉、安全日志等另有法定留存要求的，按适用法律和必要范围保存，并在对应功能启用前具体披露；不得将本说明误读为所有日志均只保留12小时。当前短期运维计时日志的轮转，与依法需要的安全日志管理是不同事项，平台应另行核查适用义务。
7. 个人信息目的已实现、期限届满、依法撤回同意或存在其他删除事由时，依法删除或匿名化；法律要求保留，或者技术上难以立即删除的，在法律允许范围内限制处理，仅进行必要存储和安全保护，并向请求人说明。

第四条　公开展示、服务提供者与跨境

1. 官网成功交互流会公开简化局面和推荐着法等内容；FEN可以被公众复制研究。请勿提交无权公开、涉及保密义务或不适合公开的棋局。公开记录不展示原图及客户关联标识，不能把熟悉某棋局的人可能辨认其来源的风险表述为零。
2. 平台使用云主机和必要网络服务处理请求，训练库拟在境内存储和处理。对受托服务提供者，应约定处理目的、期限、方式、资料类型、安全义务及处理结束后的安排，并进行必要监督；不因委托而放弃自身法定义务。
3. 当前公布的加速入口使用Cloudflare网络，可能经境外节点处理和转发，不能保证请求全程仅在境内。涉及个人信息出境时，平台应在相应使用前完成依法适用的专门告知、单独同意及其他出境要求；本协议不代表这些手续已经完成，也不以用户选择加速网址代替所需程序。
4. 除法律允许、履行有效约定并完成所需程序的情形外，不向独立第三方出售或提供用户个人信息、原始截图或训练素材。训练成果依法使用，与发布原始数据集是两件事；后者不在本次概括许可内。
5. 点击外部研究链接会将URL中携带的棋局交给目标网站；目标网站按其自身规则处理。平台不向该链接附加API密钥、客户标识或原始图片。

第五条　用户申请与响应

1. 用户可以联系 lgt@rakubank.com 或客服微信 lgtqcn，申请查阅、复制、更正、删除依法可识别的个人信息，撤回基于同意的处理，或提出停止后续训练使用的请求。请勿在公开评论或邮件中发送密钥明文；平台可提供安全核验方式。
2. 平台应合理核验请求人身份、权限及材料范围。可提供局面内容、样本指纹、上传的大致时间或其他必要定位线索；不能定位的，应说明情况并协助澄清，不以收集不必要证件作为默认前提。
3. 平台在收到完整必要信息后15个工作日内答复；法律另有期限的从其规定。对依法或依有效约定应予支持的停止后续训练请求，在核实后停止将可定位素材用于新增训练，并删除或隔离相应可独立使用样本；依法需要保留的授权或争议证明材料除外。
4. 撤回个人信息同意不影响撤回前基于有效同意进行的处理效力。素材删除不当然等于所有模型技术上已经遗忘该素材；对仍包含可识别个人信息、侵权内容或依法需要整改的模型及输出，平台应依法采取必要措施，不以“已经训练”为由概括拒绝。
5. 对已经真正匿名、无法合理重新关联个人的局面，平台应如实说明定位和个人权利适用的技术边界；仍能通过样本内容定位并符合停止使用条件的，按前述程序处理，不为响应请求重新建立不必要的身份关联。
6. 对拒绝、延期或仅部分处理的申请，平台应说明事实和法律依据，并告知可进一步投诉或依法寻求救济的途径，不保留不受审查的最终决定权。

第六条　安全、事件与未成年人

1. 平台应按照数据类型和风险采取访问控制、最小权限、传输保护、期限清理、必要备份及操作审计等措施。不能承诺绝对安全或不可能泄露，也不能据此免除依法应尽的保护义务。
2. 发生或者可能发生个人信息泄露等事件时，应依法采取补救措施，并按适用要求向有关主管部门及受影响个人通知。不得以用户同意协议代替安全责任。
3. 涉及依法需要监护人参与的未成年人信息，应先完成相应专门规则和法定程序；在不具备必要条件时，不将相关素材纳入训练库。

第七条　更新与生效

1. 训练采集仅在相应功能已经具备、规则正式公布且存在有效授权或其他合法基础后启用；不是发布一个网页就自动开始采集。
2. 目的、范围、期限或处理方式发生重大变更时，应依法显著告知并完成必要的重新确认，不将继续浏览、默认勾选或旧密钥调用当然视为新的同意。
3. 本说明与用户服务协议同版本提供查阅和保存。用户确认以正式接受记录为准；未确认用户不因本说明发布而产生新增授权。

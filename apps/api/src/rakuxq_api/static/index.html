WHY RAKUXQ

不是一次短期模型实验

它来自一个棋手把兴趣、程序设计与神经网络持续连接近二十年的尝试。

“先让机器准确看懂局面，再让它认真思考下一步。”

RakuXQ 由李国泰（rakulgt）与罗酷智能发起。项目坚持本地视觉推理、可审计拒识和整盘准确率优先，不依赖图生文大模型猜测棋局。

  1. 1988
    学会中国象棋五岁启蒙，此后长期保持实战兴趣。
  2. 2008
    lgtXQ 引擎手工线性评估函数与 Alpha-Beta 搜索。
  3. 2018
    RakuXQ 与 NNUE神经网络评估函数与新一代搜索体系。
  4. 2023
    视觉识别原型让屏幕与实体棋盘进入计算流程。
  5. 2026
    开放 HTTP API面向真实图片、Apple 快捷指令与开发者。
